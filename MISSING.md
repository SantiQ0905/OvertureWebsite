# Overture Website — Missing Content & Configuration

Last purged: 2026-08-10 (resolved items removed — see git history for the full log of
what's already been fixed). Generated by scanning `src/` for `TODO`/`pending` markers,
`public/OverData/*.md` for unsynced robot data, and the MVP spec for scope not yet built.
Items are grouped by what's blocking them: **DATA** (already exists in an `OverData` MD,
just needs syncing into code), **CONTENT** (needs to be supplied/written from scratch),
**MEDIA** (image/video/logo assets), and **CONFIG** (a real URL/link/integration to wire in).

---

## 1. Robots

- **CONTENT — Two robot MDs are still fully unfilled placeholders** (Name/Game/Events/Stats
  blank): `FLL/Rigoberto.md`, `FLL/MaxVerstappen.md`. Rigoberto has a placeholder entry in
  `robots.ts` (identity/tagline only); MaxVerstappen isn't in `robots.ts` at all. Season/game/
  event history needs to be supplied for both.
- **MEDIA — No robot has a photo.** Every `Robot.image` is `undefined`, so every card/detail
  page falls back to the generic `Tachometer` icon. MVP spec calls for a "photo with subtle
  grain/VHS-style treatment" per robot. Needs real photos dropped in `public/assets/` (folder
  doesn't exist yet — only `public/images/logos/...` exists) and `image` set per robot.
- **CONTENT — `drivetrain` / `mechanisms` / `programming` copy is "Por definir"/"To be
  determined" for every robot**, in both languages. Every MD's "Tech Info" section (Drive
  Train, Mechanisms, Programming) is unfilled — needs real descriptions.
- **CONFIG — Onshape links are missing from every robot.** GitHub repo links are in for the
  11 robots that have one; the "Onshape" field from each MD's Tech Info section has never
  been supplied for any robot.
- **CONTENT — `awards` is empty for every robot except Hornet, Diavel, Valkyrie, and
  Hayabusa.** Daytona, Maverick, Miura, Shellby all have an "## Awards" section in their MD
  but it's still the unfilled "1. List of awards / 2. Sponsors / 3. Social Impact" template.
- **CONTENT — "Sponsors" and "Social Impact" sub-items under each MD's Awards section are
  unused.** Not modeled in `Robot` at all — unclear if these should map to per-robot sponsor
  shoutouts / community-outreach notes, or get dropped. Needs a decision before more MDs get
  filled in with that structure.
- **DATA — Skyline, DeLorean, and Mulssane are minimal entries** (season + GitHub link only).
  Their MDs (`FRC/Skyline.md`, `FRC/DeLorean.md`, `FRC/Mulssane.md`) still have no Game/
  Events/Stats/Awards filled in.

## 5. Technical / infra gaps

- **No production domain decided yet.** `index.html`'s `og:image` is a relative URL (should
  be absolute once a domain exists, per OG spec — some scrapers don't resolve relative image
  URLs correctly), and both `public/sitemap.xml` and `public/robots.txt` use a placeholder
  `overture7421.example` domain that needs a single find-and-replace once a real one is
  chosen. No `<link rel="canonical">` yet either, same blocker.
- **No dedicated social-card image.** `og:image`/`twitter:image` currently point at the raw
  `OVT_FRC_Colour.png` logo (2100×1500, mostly white space) — not cropped for the 1.91:1
  aspect ratio most link-preview cards expect. A purpose-built ~1200×630 image would look
  better than the fallback.
- **No deployment config** (no `vercel.json` / `netlify.toml` / GitHub Actions workflow) —
  unclear how/where this site actually ships.
- **No automated tests** — no test runner configured in `package.json`.

   find-replace the placeholder domain in `sitemap.xml`/`robots.txt` (§5).
5. Infra cleanup (deploy config, tests) whenever there's a lull — doesn't block content work.
